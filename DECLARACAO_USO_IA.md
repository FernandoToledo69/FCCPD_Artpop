# Declaração sobre o uso de Inteligência Artificial

## Requisito atendido
Este documento cumpre o requisito **"Declaração sobre o uso de inteligência artificial"**
solicitado para este trabalho.

## Ferramenta utilizada
- **Ferramenta:** Claude (assistente de IA da Anthropic)
- **Data de uso:** 22/09/2026

## Como a IA foi utilizada
A IA foi utilizada para **gerar a estrutura inicial do código-fonte** do projeto
(as classes `Estoque`, `Pedido`, `FilaDePedidos`, `ProcessadorDePedidos`,
`LogConfiavel` e `Main`).

A IA também escreveu os comentários explicativos presentes no
código, com o objetivo de tornar cada solução compreensível.

Também foi utilizada para criar um roteiro para compilar e executar o programa

## O que NÃO foi feito pela IA
- A IA não definiu os requisitos do trabalho, apenas os implementou.
- A IA não substitui o entendimento do autor sobre o conteúdo: recomenda-se
  fortemente que o(a) estudante leia os comentários de cada classe, execute o
  programa, observe o arquivo `marketplace.log` gerado e seja capaz de explicar,
  com as próprias palavras, por que cada solução resolve o problema ao qual se
  propõe.

## Responsabilidade
O autor do trabalho é responsável por revisar, compreender e, se necessário,
adaptar o código antes de submetê-lo, respeitando as normas de integridade
acadêmica da instituição de ensino.
